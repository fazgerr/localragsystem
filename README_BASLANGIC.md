# Başlangıç

Bu klasör tamamlanmış AGÜ IE Staj Asistanı v4.0.6 teslim paketidir. Uygulama yalnızca AGÜ Endüstri Mühendisliği Bölümü staj süreçleri için hazırlanmıştır.

Çalıştırmak için önce [README.md](README.md), Windows'a özel adımlar için [SETUP_WINDOWS.md](SETUP_WINDOWS.md) dosyasını izleyin.

`MASTER_PROMPT.md` ve `KABUL_KRITERLERI.md` geliştirme/kabul bağlamını kaydeder; uygulamayı çalıştırmak için komut veya talimat kaynağı değildir. Kanonik içerik otoritesi `sources/original/` altındaki beş dosyadır.

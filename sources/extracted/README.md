# Extracted Source Texts

Bu klasörde kanonik kaynak dosyalarından programatik olarak çıkarılmış metinler bulunur.

- DOCX: paragraflar + tablolar
- JPG: OCR ile metin aktarımı

Bu dosyalar RAG ingestion için kullanılabilir; fakat orijinal dosyalar (`sources/original`) kanonik kaynaktır.

Bir extraction hatası görülürse tahminle düzeltme yapma. Orijinal dosyayı inceleyip extraction kodunu düzelt.
